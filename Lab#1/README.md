# Розпаралелювання алгоритму обрахунку суми елементів масиву

## Завдання

Реалізуйте мінімум на двох мовах програмування, які мають вбудовану підтримку роботи з потоками (Java, C#, C++, Ada, Kotlin, Dart, Go, Rust...  ), програму, яка б обраховувала суму елементів масиву (кількість елементів у масиві має бути неменшою за 1000000000), розбивши його на наперед задану кількість частин і знаходячи суму кожної частини у окремому потоці з наступним синхронним об'єднанням проміжних сум у загальний результат.<br>
Кінцева мета розпаралелювання у цьому випадку полягає у зменшенні часу роботи алгоритму обрахунку суми елементів масиву, тому ефективність роботи (часу виконання) запропонованих реалізацій слід порівнювати з часом роботи однопоточної реалізації методу.<br>
Причому можна привести по декілька реалізацій зазначеного способу розпаралелювання для знаходження суми елементів масиву на кожній з мов програмування, зокрема з використанням як стандартних так "просунутих" засобів управління потоками у тій чи іншій мові програмування. Кожна додаткова реалізація та пояснення до неї будуть оцінюватися додатковими балами.<br>
Для кожної із запропонованих багатопоточних реалізацій потрібно робити висновок про її ефективність у порівнянні з іншими багатопоточними реалізаціями алгоритму.
