# Java: Розпаралелювання алгоритму обчислення суми елементів масиву методом здвоювання (хвильовий алгоритм)

Проєкт містить реалізації хвильового згортання масиву розміром 1 млрд елементів за $O(\log N)$ кроків із симетричним додаванням пар елементів «на місці» (in-place).

---

## 1. SingleThreadedWaveSum
Однопотокова базова версія алгоритму для перевірки коректності результатів та оцінки швидкодії.

* **Архітектура виконання:** Обчислення виконуються послідовно в головному потоці `main` без створення додаткових потоків.
* **Синхронізація:** Відсутня; операції виконуються детерміновано крок за кроком без накладних витрат на блокування чи перемикання контексту.
* **Розподіл навантаження:** На кожній хвилі потік послідовно проходить усі пари від `0` до `len / 2`, зсуваючи робочу довжину масиву.

---

## 2. ParallelWaveSum
Багатопотокова версія на основі стандартних потоків Java (`Thread`) та синхронізаційного примітива `CyclicBarrier`.

* **Архітектура виконання:** Модель «керуючий потік (`main`) + пул робочих потоків (`Worker`)». Кількість потоків визначається за `Runtime.getRuntime().availableProcessors()`.
* **Синхронізація (`CyclicBarrier`):** Використовується двофазний бар'єр на $N + 1$ учасників (усі робочі потоки + керуючий потік):
  1. *Перший бар'єр:* потік `main` очікує, поки всі worker-потоки завершать підсумовування пар поточної хвилі.
  2. *Фаза оновлення:* керуючий потік перераховує актуальну довжину масиву `currentLength = (currentLength + 1) / 2` або встановлює прапорець зупинки.
  3. *Другий бар'єр:* робочі потоки отримують сигнал про початок нової хвилі з оновленими межами.
* **Розподіл навантаження:** Загальна кількість пар кожної хвилі рівномірно нарізається на діапазони (`chunkSize`) між активними worker-потоками.
