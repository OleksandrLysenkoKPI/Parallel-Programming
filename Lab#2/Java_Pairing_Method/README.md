# Java версія: Розпаралелювання алгоритму обрахунку суми елементів масиву методом здвоювання (хвильовий алгоритм)

## SingleThreadedWaveSum
Послідовна (однопоточна) реалізація алгоритму здвоювання в одному масиві «на місці». Вона демонструє базову логіку хвильового згортання та створює еталон для оцінки правильності результатів і підрахунку підрахунку коефіцієнта прискорення паралельних версій.

## ParallelWaveSum
Багатопотокова версія алгоритму на основі стандартних потоків Java та примітивів пакета `java.util.concurrent`.

* **Архітектура:** Модель взаємодії «керуючий потік + пул робочих потоків (Worker)». Кількість потоків адаптується під число доступних логічних ядер процесора.
* **Розподіл задач:** На кожній хвилі загальна кількість пар рівномірно нарізається на чанки (`chunkSize`), які закріплюються за відповідними worker-потоками.
* **Синхронізація (`CyclicBarrier`):** Для координації фаз використовується бар'єр на `N + 1` учасників (усі робочі потоки + потік `main`):
    1. **Перший бар'єр:** Очікування завершення обчислень поточного кроку всіма робітниками.
    2. **Фаза оновлення:** Керуючий потік перераховує нову діючу довжину масиву або виставляє сигнал зупинки.
    3. **Другий бар'єр:** Одночасний старт робітників на новій хвилі з актуальними даними.
